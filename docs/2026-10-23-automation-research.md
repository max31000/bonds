## T-Invest API
- REST/gRPC. Токены: только чтение, полный доступ, на один счёт, для переводов (только на все счета), песочница.
- Токен живёт 3 месяца без использования. Ограничения: ≈ 50 запросов/с, 1000 запросов/мин с одного IP.
- Есть лимитные, рыночные и стоп-заявки. Вывода денег на карту через API нет [?] — вывод остаётся ручным.
- Python SDK `t-tech-investments` ставится только из приватного индекса opensource.tbank.ru.
- TLS-цепочка от Russian Trusted Root CA: корень закреплён в `certs/` (SHA-256 D26D…CF31).

## ИИ-агенты в трейдинге (что известно на 10.2026)
- Короткие турниры (Alpha Arena) — единичные прогоны, не доказательство.
- Многомесячные бенчмарки без подглядывания в будущее (StockBench, FINSABER, Look-Ahead-Bench): модели в среднем не обгоняют «купил и держи».
- Где модели реально сильны:
  - разбор отчётов и новостей;
  - мониторинг событий (оферты, дефолты, рейтинги);
  - исполнение формальных правил и проверка аномалий.
- Вывод для дизайна: агент **предлагает и следит**, детерминированный движок **считает**, исполнение — по жёстким лимитам или с подтверждением.
