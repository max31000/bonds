### Инвариант

Каждая позиция пользователя попадает ровно в одну корзину своего портфеля:
- явный член корзины;
- иначе — правило класса;
- иначе — системная корзина `unassigned`.

## Что сделать

1. **Сид по умолчанию.** Делается при первом GET, если у пользователя нет корзин, а не в миграции — данные пользовательские.

   Портфель **rub**:

   | Корзина | Цель | band / hard | Тир | Правило | Состав / флаги |
   |---|---|---|---|---|---|
   | `liquidity` | 0.15 | 0.05 / 0.10 | 0 | fixed | TMON@ 0.5, TSAV 0.5; `auto_buy`=1, `auto_sell`=1 |
   | `bonds` | 0.85 | 0.05 / 0.10 | 2 | engine | asset_class bond |
   | `ru_equity` | 0 | 0.02 | 1 | fixed | без членов |
   | `temporary` | null | | 1 | hold | TPAY, TOFZ@ |

   Портфель **usd**:

   | Корзина | Цель | Тир | Правило | Состав / флаги |
   |---|---|---|---|---|
   | `global_core` | 1.0 (решение владельца: satellites/frozen вне целей, Σ=1) | 1 | fixed | VUAA.EU 0.8, SPYM.US 0.2; правило доливки — задача 63 |
   | `satellites` | null | 2 | hold | LUV, UFO, ROBO, SJPA, LGQM, OTGLY |
   | `frozen` | null | 3 | hold | FNMA, FMCC |

   Цели — стартовые. Пользователь правит их в UI.

2. **`BasketDriftService`** (Core, чистая функция).
   - Вход: позиции всех брокеров со стоимостью в валюте портфеля (rub — рубли, usd — доллары по курсу),
     свободные деньги, корзины.
   - Выход по каждой корзине:

     | Поле | Единица |
     |---|---|
     | `value` | валюта портфеля |
     | `weight` | ДОЛЯ |
     | `target` | ДОЛЯ |
     | `drift` | ДОЛЯ |
     | `state` | `Ok` \| `Below` \| `Above` \| `HardBelow` \| `HardAbove` \| `NoTarget` |
     | `deficitToTarget` | валюта портфеля |

   - База доли: портфель минус корзины с `target_weight = null`. Временная корзина и спутники не размывают цели.
   - Свободный кэш — отдельная строка `cash`, в базу входит.

3. **API.**
   - `GET /api/baskets` → корзины, члены и drift.
   - `PUT /api/baskets/{id}` — цели и флаги. Валидация: сумма `target_weight` в портфеле = 1 ± 0.0001, иначе 422; band < hard_band.
   - `POST/DELETE` для членов.
   - `POST /api/baskets/reset-defaults`.

4. **Тесты.**
   - Drift на эталоне руками: портфель 1 000 000, ликвидность 120 000 при цели 0.15 → drift −0.03, `Below`, дефицит 30 000.
   - Исключение `null`-корзин из базы.
   - Каждая позиция ровно в одной корзине.
   - 422 при сумме ≠ 1.

5. **Фронт.**
   - Новая страница **«Капитал»** (`/capital`, пункт навигации; видна всем, раздел usd — при `capabilities.freedom`).
   - На странице по портфелям: корзины с целью, фактом, полосой отклонения (бар цель/факт с band), состоянием,
     составом; редактирование целей в форме. Ввод в %, а в API уходят ДОЛИ — конверсия один раз.
   - Дисклеймер «оценка, не рекомендация».
   - Vitest: рендер, конверсия % → доля, 422.
